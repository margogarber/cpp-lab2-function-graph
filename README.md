# Лабораторна робота №2 — «Графічний інтерфейс користувача»

**Виконала:** Гарбєр Маргарита Олександрівна, група ІА-з41
**Варіант:** 4

Віконний Win32-додаток мовою C++, який будує графік функції засобами GDI. Функція задається
у коді програми, діапазон зміни аргументу — константою. Програма автоматично визначає масштаб
так, щоб усі значення функції помістилися у вікні, і перебудовує графік при зміні розмірів вікна.

## Завдання варіанту 4

Написати програму для побудови графіка функції, заданої користувачем. Рівняння задається у
вигляді функції, а діапазон зміни аргументу — константою. Програма автоматично визначає масштаб
і виводить графік так, щоб усі значення функції помістились у вікні додатку.

## Можливості

- три функції з власними діапазонами аргументу (масив `kFunctions` у `src/main.cpp`):
  - `f(x) = x · sin(x)`, x ∈ [−10; 10]
  - `f(x) = x³ − 6x² + 4x + 12`, x ∈ [−2; 6]
  - `f(x) = e^(−x/4) · cos(2x)`, x ∈ [−2; 10]
- автоматичний масштаб по осі Y за мінімумом і максимумом функції (+5 % поля);
- сітка з «круглим» кроком (1, 2, 5 · 10ⁿ), підписи значень, осі координат;
- перемальовування з подвійною буферизацією при зміні розмірів вікна;
- вікно 800 × 600 по центру екрана;
- вибір функції: меню **Функція** або клавіші **1**, **2**, **3**; вихід — **Esc** або **Файл → Вихід**.

Щоб побудувати іншу функцію, додайте її в масив `kFunctions` разом із межами `xMin`, `xMax`.

## Вимоги

- Windows 10/11 (x64 або ARM64)
- Visual Studio 2019/2022/2026 з компонентом «Desktop development with C++» **або** MinGW-w64 (g++)

## Збірка

**Visual Studio:** File → Open → Folder… → вибрати теку репозиторію (VS відкриє `CMakeLists.txt`),
вибрати ціль `Lab02.exe` і запустити (F5).

**Developer PowerShell for VS (MSVC):**
```
mkdir build
cl /std:c++17 /W4 /utf-8 /EHsc /DUNICODE /D_UNICODE src\main.cpp /Fe:build\Lab02.exe /Fo:build\ /link user32.lib gdi32.lib /SUBSYSTEM:WINDOWS
```

**CMake:**
```
cmake -S . -B build
cmake --build build --config Release
```

**MinGW-w64:**
```
build_mingw.bat
```

## Запуск

`build\Lab02.exe` (або `build\Release\Lab02.exe` для CMake + MSVC). Змініть розмір вікна —
графік перебудується з новим масштабом.
